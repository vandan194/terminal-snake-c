# Terminal Snake Game in C

A classic Snake game made in C using the ncurses library for terminal graphics and input handling.

## Features

- Smooth snake movement
- Real-time keyboard controls
- Score system
- Random berry spawning
- Collision detection
- Restart system
- Colored terminal rendering
- Game over screen

## Requirements

- GCC compiler
- ncurses library

Compile:

```bash
gcc snake.c -o snake -lncurses
